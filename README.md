# Folleto digital interactivo — Riesgos físico-químicos

Web estática y responsiva elaborada a partir del documento `Folleto(1).docx` de la Universidad Francisco de Paula Santander.

## Cómo abrir

1. Descomprime el archivo ZIP.
2. Abre `index.html` con Chrome, Edge, Safari o Firefox.
3. Funciona sin Internet y sin instalar dependencias.

## Cómo publicar en GitHub Pages

1. Crea un repositorio público en GitHub.
2. Sube `index.html`, `styles.css`, `script.js` y **toda la carpeta `assets`** a la raíz del repositorio.
3. En `Settings → Pages`, elige `Deploy from a branch`, rama `main`, carpeta `/ (root)` y guarda.
4. Espera la publicación y abre el enlace que GitHub mostrará en `Pages`.

También se proporciona el archivo `Folleto_Interactivo_UFPS.html` como **versión de un único archivo**: contiene imágenes, estilos y scripts integrados; puedes abrirlo directamente sin extraer el ZIP.

## Funciones

Navegación adaptable a móvil, triángulo interactivo, filtros de las nueve medidas de prevención, marcas de contenido revisado guardadas localmente, pasos de emergencia seleccionables, clases de fuego y un cuestionario de cinco preguntas con evaluación inmediata.

**Aviso**: Recurso educativo. La interacción de la web no sustituye la capacitación, el plan de evacuación ni los procedimientos de seguridad de una mina.
